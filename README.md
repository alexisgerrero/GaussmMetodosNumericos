## Ejemplo de prueba
Sistema:

```
3.0x1 - 0.1x2 - 0.2x3 =   7.85
0.1x1 + 7.0x2 - 0.3x3 = -19.3
0.3x1 - 0.2x2 + 10x3  =  71.4
```

Salida por consola:

```
Soluciones del sistema:
x1 = 3.0
x2 = -2.5
x3 = 7.000000000000002
```

Solución esperada: x1 = 3, x2 = -2.5, x3 = 7
